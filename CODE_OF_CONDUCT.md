# Code of Conduct

## Our commitment

We want this project to be a welcoming place to learn, contribute, and review
code — regardless of experience level, background, or which issue "level"
you're starting at. Everyone interacting in this repository's issues, pull
requests, discussions, and any other project space is expected to help keep
it that way.

## Expected behaviour

- Be respectful in code review — critique the code, not the person.
- Assume good faith. Most confusing PRs are the result of a misunderstanding,
  not carelessness.
- Be patient with newer contributors, especially around Open Source Connect
  India (OSCI) participants working through Level 1/Level 2 issues for the
  first time.
- Give specific, actionable feedback rather than vague rejections.
- Respect maintainers' decisions on scope — not every idea fits this
  project's thesis (see the README's "Not built, on purpose" section).

## Unacceptable behaviour

- Harassment, insults, or personal attacks in issues, PRs, or commits.
- Discriminatory jokes or language, in any form.
- Publishing others' private information without consent.
- Deliberately derailing issues or PRs, or spamming `/claim` on issues you
  don't intend to work on.
- Plagiarizing another contributor's solution and submitting it as your own.

## Scope

This applies to all project spaces — issues, pull requests, commit messages,
code review comments — and to any other communication (e.g. Discord, mailing
lists) that references this project.

## Reporting

If you experience or witness behaviour that violates this code of conduct,
please open a private report by contacting a maintainer directly (via their
GitHub profile) rather than posting publicly. Reports will be reviewed and
handled with discretion, and retaliation against a reporter will not be
tolerated.

## Enforcement

Maintainers may remove comments, close issues/PRs, or temporarily or
permanently ban anyone whose behaviour is deemed inappropriate, threatening,
offensive, or harmful. Maintainers who do not follow or enforce this code of
conduct in good faith may face the same consequences.
